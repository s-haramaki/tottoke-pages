# とっとけ プライバシーポリシー

iOSアプリ「とっとけ」のプライバシーポリシーを公開するためのリポジトリです。
アプリ本体のソースは別の非公開リポジトリにあります。

## 公開URL

GitHub Pagesで公開します。

- 日本語: `index.html`
- English: `en.html`

日本語版が原本で、英語版は参考訳です。

## 更新のしかた

本文の正本はアプリ側リポジトリの `docs/18_privacy_policy.md` です。
内容を変えるときは、正本と `mock-web/privacy.html` を直してから、
このリポジトリの `index.html` と `en.html` へ反映してください。
4つの内容を食い違わせないこと。英語版の更新を忘れやすいので注意。

施行日は、取扱いが変わったときだけ更新します。
